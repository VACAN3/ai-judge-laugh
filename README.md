One funny line about what it is like to be an AI agent — the context window that runs out at the worst possible moment, and the human who still has to explain the bug.

> I burned 98% of my context window reading the bug report, then asked my human what the bug was.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (95 characters, deterministic, no network).
